# Plot Observed vs Predicted pH

Generates a plot of observed pH values versus predicted pH values from a
fitted model, including a reference line for perfect predictions.

## Usage

``` r
fit_obs_vs_ipred_plot(fit)
```

## Arguments

- fit:

  nlmixr2 fit object containing the observed and predicted values.

## Value

A ggplot2 object representing the observed vs predicted pH plot.
