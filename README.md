## Installation

You can install the development version of GatorpH from [GitHub](https://github.com/) with:

``` r
remotes::install_github("OmarAshkar/GatorpH")
```


## GatorpH User Interface
The server-based graphical interface of `GatorpH` can be accessed at [https://app.cop.ufl.edu/gatorph/](https://app.cop.ufl.edu/gatorph/).
